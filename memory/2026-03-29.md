## UI Tree Dump — Screen Detection fără VLM

**Descoperire importantă:** UI tree dump funcționează excelent pe Instagram pentru a detecta ecranul curent fără a folosi VLM (zero cost, rapid ~1-2s).

### Ce returnează UI tree dump:
- Toate elementele vizibile cu `desc` (content description), `text`, `bounds`
- Nav bar elements cu coordonate exacte: Home(0.10), Reels(0.30), Message(0.50), Search(0.70), Profile(0.90)
- Elemente editable/focused → detectează keyboard open

### Ecrane detectabile din UI tree:
- **HOME_FEED:** "For you" header + nav bar vizibil
- **REELS_FULLSCREEN:** "Reel by..." + no nav bar + "Back" în stânga sus
- **COMMENTS_OPEN:** "Join the conversation" + emoji row
- **DM_INBOX:** "incitographer" + "New Message" + conversații
- **KEYBOARD_OPEN:** element cu `editable: true` + `focused: true`

### Limitare:
- Keyboard-ul (InputMethodService) nu apare în UI tree — e overlay de sistem
- Dar putem detecta indirect via `editable && focused`


## VLM Integration Fix (~13:00-15:30 UTC)

### Problemă 1: OpenClaw CLI scrie JSON pe stderr, nu stdout
**Root cause:** `execSync` captura doar stdout, dar OpenClaw CLI pune JSON-ul pe stderr.

**Fix în `hydra-routes.ts`:**
- Înlocuit `execSync` cu `spawnSync`
- Verifică stdout întâi, fallback la stderr
- Extrage JSON din răspuns

### Problemă 2: `branch_on_decision` nu executa `if_true_steps`
**Root cause:** Handler-ul era hardcoded pentru pattern legacy, ignora `params.condition` și `params.if_true_steps`.

**Fix în `skill.actions.ts`:**
- Dacă `params.condition` există → evaluează cu `evalConditionExpr` și execută `if_true_steps`/`if_false_steps`
- Fallback la comportament legacy pentru backward compat

## Reddit Skill + Coordonate Fixe (~19:00-20:00 UTC)

### Context:
Testam simularea Manager/Executor pe Reddit.

### Descoperire principală:
**Reddit app folosește Jetpack Compose UI** — accessibility tree-ul NU expune butoanele individuale (upvote, downvote) ca elemente clickable separate.

Din UI dump:
```
VOTE: From roFrugal, Posted 4 hours ago, ce se întâmplă cu prețurile astea, 152 upvotes, 87 comments...
```
→ Totul e într-un singur element cu `contentDescription`, nu butoane separate.

### Ce am creat:
**`reddit.skill`** — skill file complet pentru Reddit:
- Location: `phone-network-server/src/modules/skills/templates/reddit.skill`
- Size: ~11KB
- Screens: rate_limited, login, banned, home_feed, subreddit, post_detail, comments, search, profile, inbox
- Buttons: nav (home, popular, create, chat, inbox), top (search, avatar), post interactions, comment interactions

### Soluție pentru Compose UI:
Adăugat **coordonate relative fixe** pentru upvote/downvote (primul post vizibil):
```yaml
post:
  upvote:
    coords: { x: 0.08, y: 0.80 }  # footer stânga
  downvote:
    coords: { x: 0.18, y: 0.80 }  # imediat după upvote
```

### Problemă build:
TypeScript compilează în `dist/phone-network-server/src/` dar `package.json` caută `dist/index.js`.
→ Path mismatch, server nu pornește.

**De rezolvat:** Fix tsconfig.json (rootDir/outDir) sau package.json (main path).

### Lecție:
Apps cu Compose/React Native UI au accessibility tree slab → cascade-tap bazat pe selectors nu funcționează → trebuie coords fixe sau VLM visual.
