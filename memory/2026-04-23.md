## Critical Issue: Qwen 3.6 Tool Calling Failure

**Root Cause Identified (2026-04-23):**

Qwen 3.6 does NOT support proper tool calling for OpenClaw:

| Model | Tool Call Format | Detection | Status |
|-------|------------------|-----------|--------|
| Gemma 4 | `tool_calls` JSON array | ✅ Working | ECHO uses successfully |
| Qwen 3.6 | XML-like `<function=read>` in `content` | ❌ Failing | LENS, SPARK blocked |

**What Happens:**
1. Qwen 3.6 with parser `llama3_json` emits XML-like format instead of standard JSON
2. OpenClaw expects `"tool_calls": [{"type": "function", "function": {...}}]`
3. OpenClaw cannot detect tool → re-prompts model → infinite loop

**Verified NOT a vLLM parser issue:**
- `curl` tests confirm vLLM emits correct JSON `tool_calls`
- Problem is model-level capability for complex workflow tasks
