## Arhitectura EXECUTE_TASK (Phone Network Automation)

### Concept
Framework de automatizare phone task-uri — similar cu Agentic SMB dar pentru Reddit/app-uri pe telefon.

### Implementare

**Server → tip nou de mesaj WebSocket:**
- `EXECUTE_TASK` — server trimite task către telefon
- `EXECUTE_TASK_RESULT` — telefon trimite rezultatul înapoi

**Endpoint API nou:**
- `POST /api/tasks/execute` — accepts `{deviceId, taskType, params}`
- Trimite task prin WebSocket către device

**Android Agent:** primește EXECUTE_TASK, execută cu JobExecutor, trimite rezultat

**Task types implementate:**
- `reddit_navigate_subreddit` — deschide Reddit, navighează la un sub
- `reddit_upvote_post` — upvote la post-ul curent
- `reddit_comment_post` — adaugă comentariu la post-ul curent
- `reddit_scroll_to_next` — scroll la următorul post
