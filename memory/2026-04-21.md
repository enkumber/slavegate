### IB-06: Integration Tests - BLOCKED

**Problem:** LENS (Qwen 3.6 35B NVFP4) is blocked in infinite loop, saying "I'll start reading STORY-IB-06" but never reading or writing any tests.

**Root Causes:**
1. **Qwen 3.6 model is too small/slow** for complex integration testing (end-to-end, E2E mocks, metrics, multi-module tests)
2. **Tool calling compatibility issue:**
   - Qwen 3.6 with `llama3_json` parser emits tool calls in XML-like format inside `content`: `<function=read><parameter=path>...</parameter></function>`
   - OpenClaw expects JSON format: `"tool_calls": [{"type": "function", "function": {"name": "...", "arguments": {...}}]`
   - OpenClaw doesn't detect XML format → LENS never executes tools → prompt reloads → infinite loop

**Attempts Made (all failed):**
- Restarted Qwen container with `--tool-call-parser llama3_json` (correct parser per docs)
- Tested with curl: tool calls JSON format works ✅
- Moved LENS to Gemma 4 (which works perfectly with tool calling) - still blocked
- Disabled `compat.supportsTools: false` - caused gateway config error
- Split IB-06 into 3 smaller stories (06A, 06B, 06C) - still blocked
- Large timeouts (180s) - still blocked
- Created STORY-IB-06 in LENS workspace (was in ATLAS workspace, wrong path)

**Conclusion:** Qwen 3.6 (LENS, SPARK) is insufficient for complex integration/testing tasks. 35B NVFP4 model is optimized for fast inference, not for complex reasoning + multi-module test writing.
