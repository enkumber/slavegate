### Descoperiri Cheie

1. **Butoanele vote sunt ASCUNSE din accessibility tree**
   - Reddit folosește `setImportantForAccessibility(IMPORTANT_FOR_ACCESSIBILITY_NO)` pe VoteViewLegacy
   - `vote_view_upvote` și `vote_view_downvote` NU apar în UI tree

2. **Soluția: Bounds-relative tapping**
   - Găsim containerul vizibil (`vote` sau `link_footer_root`)
   - Tap la 10% din width = upvote
   - Tap la 22% din width = downvote

## type_text Timeout Fix (11:21 UTC)

### Problema
- type_text cu 272 caractere da timeout la 30s
- Device-ul folosește human-like typing cu multiple delays:
  - Inter-char: 40-90ms
  - Inter-word: 100-250ms
  - Typo simulation (~4%): +200ms each
  - Thinking pauses (~4%): +550ms each
- Observat în practică: **~660ms per caracter** (mult mai mult decât estimarea inițială)

### Fix-uri aplicate

1. **Timeout dinamic per text length** (dispatcher.service.ts):
   - Formula: `textLength * 700 + 15000` ms
   - 272 caractere → 205 secunde (~3.5 minute)
   - `skipMaxClamp = true` — type_text ignoră MAX_TIMEOUT_MS

2. **Timeout pasat la device** (routes.ts):
   - `dispatcherService.dispatch()` returnează `{ jobId, timeoutMs }`
   - `wsServer.sendJob()` primește timeout calculat, nu cel din request

3. **Inter-char delay redus** (AutomationController.kt):
   - De la 50-150ms la **40-90ms**
   - APK v2.6.6-debug deployat via OTA
