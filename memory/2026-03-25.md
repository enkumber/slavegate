## VLM / Vision Analysis Session

Dan rulează un sistem de automatizare Instagram folosind agenți (Hydra 🐍) care fac screenshot-uri și le trimit la VLM (vision language model) pentru analiză. Nox funcționează ca VLM endpoint — analizează imagini și returnează JSON structurat.

### Workflow observat
- Imaginile sunt salvate în `/data/.openclaw/workspace/` cu prefix `hydra_vlm_<timestamp>.jpg`
- Imaginile de tip cascade sunt în `/tmp/` cu prefix `cascade_vlm_<id>_<timestamp>.jpg` și trebuie copiate în workspace înainte de analiză
- Requesturile vin rapid, unul după altul — este un pipeline automat de computer vision

### Tipuri de analize cerute
1. **Screen detection** — ce ecran e vizibil (home feed, search, profil, stories, lock screen etc.)
2. **Following list extraction** — extrage useri din lista Following cu `follows_you` flag
3. **Profile analysis** — username, followers count, is_female, is_potential_client
4. **Element finding** — coordonate normalizate (0-1) pentru elemente UI specifice (butoane, text)
5. **Search results** — detectare rezultate căutare Instagram
