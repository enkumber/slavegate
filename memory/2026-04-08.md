## GX10 Setup — llma.cpp / Ollama

**ASUS Ascent GX10** — GB10 Superchip (Grace Blackwell)
- 72 CPU cores (ARM64 / aarch64)
- 128GB HBM3e GPU memory
- 116GB RAM
- 1.8TB NVMe disk

**Tunnel:** Cloudflare tunnel `https://promoting-emotions-hanging-brick.trycloudflare.com`
- Token: `token-secret-al-tau-123`
- Instabil — necesită restart periodic (`sudo systemctl restart cloudflared`)

**Problema:** `noxthebot` nu are permisiuni de write în `/tmp` pe GX10.
Directorul `/home/noxthebot/llama/` există (conform ls earlier).

**Opțiuni de instalare llama.cpp:**
1. Binary pre-built: `llama-b5578-bin-ubuntu-arm64-cublas.zip` (CUDA/cublas pentru GB10)
2. Ollama instalat: `curl -fsSL https://ollama.com/install.sh | sh`
   - Problema: `sudo` needed dar `noxthebot` nu e în sudoers
   - Ollama by default folosește `/usr/local/bin` — trebuie access

**Următorul pas:** Permisiuni corecte pentru `noxthebot` pe GX10:
```bash
sudo chown -R noxthebot:noxthebot /home/noxthebot/llama
sudo chmod u+w /home/noxthebot
```
Sau configurare corectă ssh/wget pentru download manual de Dan.
