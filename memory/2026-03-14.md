### Bug identificat: Checkpoint Conflict

**Simptom:**
```
[workflow] fbbd9871 attempt 1 failed — retrying from checkpoint: Checkpoint conflict at step 0
```

**Root cause:** BullMQ default `lockDuration` și `stalledInterval` = 30 sec. Workflow steps pot dura mai mult → BullMQ crede că job-ul e stalled → lansează retry → 2 workeri rulează simultan → checkpoint conflict.

**Fix aplicat de FORGE:**
```typescript
const worker = new Worker(WORKFLOW_QUEUE, async (job) => {...}, {
  lockDuration: 120000,      // 2 minute lock (era 30s default)
  stalledInterval: 60000,    // Check stalled every 1 min (era 30s default)
});
```

```typescript
await workflowService.saveCheckpoint(workflowId, checkpoint, iter, iter);

```

**Fix aplicat:**
```typescript
// Adăugat parametru isNested pentru nested steps în loop/condition
async function executeSteps(..., isNested: boolean = false)
// Skip checkpoint pentru nested steps — doar top-level face checkpoint
```
