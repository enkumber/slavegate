# E-E-A-T Scoring Rubric

Google's content quality framework. Per December 2025 Quality Rater Guidelines, applies to ALL competitive queries.

## Experience (25 points)

First-hand knowledge and direct involvement with the topic.

| Signal | Points | Scoring |
|--------|--------|---------|
| First-person accounts | 5 | "I tested...", "We implemented..." — 5 if specific, 3 if generic, 0 if absent |
| Original research/data | 5 | 5 if original data, 3 if references original work, 0 if none |
| Case studies with results | 4 | 4 if detailed with numbers, 2 if general, 0 if none |
| Evidence (screenshots, photos) | 3 | 3 if authentic, 1 if stock/generic, 0 if none |
| Specific examples from experience | 4 | 4 if unique, 2 if somewhat specific, 0 if generic |
| Process demonstrations | 4 | 4 if step-by-step from experience, 2 if partial, 0 if none |

**Weak Experience signals:**
- Only summarizes other sources
- Generic advice ("It depends on your needs")
- No mention of actual usage/testing
- Hedging ("reportedly", "supposedly", "some say")

---

## Expertise (25 points)

Demonstrated knowledge depth and professional competence.

| Signal | Points | Scoring |
|--------|--------|---------|
| Author credentials visible | 5 | 5 if full credentials, 3 if basic bio, 0 if no author |
| Technical depth | 5 | 5 if thorough, 3 if adequate, 0 if superficial |
| Methodology explanation | 4 | 4 if clear, 2 if some, 0 if none |
| Data-backed claims | 4 | 4 if well-sourced, 2 if some data, 0 if unsupported |
| Industry terminology correct | 3 | 3 if accurate specialized language, 1 if basic, 0 if errors |
| Detailed author page | 4 | 4 if dedicated page, 2 if brief bio, 0 if none |

**Weak Expertise signals:**
- Claims without evidence
- Surface-level coverage
- Misused terminology
- No visible author
- Broad/generic content

---

## Authoritativeness (25 points)

Recognition by others as credible source.

| Signal | Points | Scoring |
|--------|--------|---------|
| Cited by authoritative sources | 5 | 5 if major sources, 3 if some, 0 if none |
| Author in press/media | 4 | 4 if media mentions, 2 if industry, 0 if none |
| Industry awards | 3 | 3 if relevant, 1 if tangential, 0 if none |
| Speaker at conferences | 3 | 3 if listed, 0 if none |
| Published in respected outlets | 4 | 4 if tier-1, 2 if industry, 0 if none |
| Comprehensive topic coverage | 3 | 3 if thorough, 1 if some, 0 if isolated |
| Wikipedia/authoritative mentions | 3 | 3 if Wikipedia, 2 if encyclopedic refs, 0 if none |

**Weak Authoritativeness signals:**
- Single-topic site with no depth
- No external validation
- Self-proclaimed "expert"
- No authoritative backlinks

---

## Trustworthiness (25 points)

Signals that content and publisher are reliable.

| Signal | Points | Scoring |
|--------|--------|---------|
| Contact info (address, phone, email) | 4 | 4 if full, 2 if email only, 0 if none |
| Privacy policy | 2 | 2 if present, 0 if absent |
| Terms of service | 1 | 1 if present, 0 if absent |
| HTTPS valid | 2 | 2 if valid, 0 if not |
| Editorial/corrections policy | 3 | 3 if documented, 1 if implicit, 0 if none |
| Transparent business model | 3 | 3 if clear disclosures, 1 if some, 0 if none |
| Real customer reviews | 3 | 3 if verified, 1 if testimonials, 0 if none |
| Accurate claims | 4 | 4 if all accurate, 2 if mostly, 0 if errors |
| Affiliate/sponsorship disclosures | 3 | 3 if proper, 0 if undisclosed |

**Weak Trustworthiness signals:**
- No contact info
- Missing privacy policy
- Undisclosed affiliates
- Verifiably false claims

## Content Quality Metrics

### Word Count Benchmarks

| Page Type | Minimum | Ideal |
|-----------|---------|-------|
| Homepage | 500 | 500-1,500 |
| Blog post | 1,500 | 1,500-3,000 |
| Pillar content | 2,000 | 2,500-5,000 |
| Product page | 300 | 500-1,500 |
| Service page | 500 | 800-2,000 |
| About page | 300 | 500-1,000 |
| FAQ page | 500 | 1,000-2,500 |

### Readability
- Target Flesch Reading Ease: 60-70 (8th-9th grade)
- Average sentence: 15-20 words
- Paragraphs: 2-4 sentences
- Jargon defined on first use

### Freshness

| Status | Criteria |
|--------|----------|
| Excellent | Updated within 3 months |
| Good | Updated within 6 months |
| Acceptable | Updated within 12 months |
| Warning | 12-24 months ago |
| Critical | No date or 24+ months |

## AI Content Assessment

AI content acceptable if it demonstrates genuine E-E-A-T with human oversight.

**Low-quality AI signals (flag these):**
- Generic phrasing ("In today's fast-paced world...")
- No original insight
- Perfect structure, shallow content
- No specific examples
- Hedging overload ("Generally speaking...")
- Missing human voice/opinions
- Filler paragraphs

**High-quality signals (any production method):**
- Original data
- Specific examples (named products, dates, numbers)
- Contrarian/nuanced views backed by reasoning
- First-person experience
- Recent references
- Clear expert opinions
- Practical, actionable recommendations
- Trade-offs acknowledged
